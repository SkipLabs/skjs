1. Generic forwarding has no sound type

async function wrap<T>(x: T): Promise<Awaited<T>> { return x; }

The verifier's trusted contracts today:

%Await% :

∀T, U ≤ Prim. (Promise<T> | U) ⇒ T | U

%AsyncReturn% :

∀T, U ≤ Prim. (T | Promise<U>) ⇒ Promise<T | U>

T may be a promise or an object, and no type says what x becomes once a promise resolves with it. So wrap is refused.

The two trusted contracts bound the non-promise side to primitives, on which resolution never calls then. That keeps them sound but rules out any generic forwarder.
