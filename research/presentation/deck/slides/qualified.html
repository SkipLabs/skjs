4. Implied bounds: Awaited<T> constrains T

async function wrap<T>(v: T): Promise<Awaited<T>>

reads as   wrap : ∀T : Resolvable. (v: T) ⇒ Promise<T.Result>

  • Implied bound. Writing Awaited<T> in the signature gives T the constraint T : Resolvable, as if it were written there. Bounds are read off the signature, never off the body.
  • T : Resolvable means T has a classification, which fixes two associated types: T.Observed, what await yields, and T.Result, what a fresh resolution yields, never thenable. Awaited<T> is T.Result.
  • Not a subtype bound. It leaves the values of T alone; each call supplies the classification of its type argument.
  • The other implied bound: a Promise argument of an imported or library signature implies T ≤ N.
