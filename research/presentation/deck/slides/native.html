3. Native promise contracts

Promise<B> is a native promise of the realm, with stable standard prototype, constructor, methods and species. A result that is resolved again must stay non-thenable for its whole lifetime:

N = Prim | { readonly then?: Prim } | readonly unknown[]

%Await% : ∀T, U ≤ N. (Promise<T> | U) ⇒ T | U

%AsyncReturn% : ∀T ≤ N, U ≤ N. (T | Promise<U>) ⇒ Promise<T | U>

%PromiseResolve% : ∀T, U ≤ N. (Promise<T> | U) ⇒ Promise<T | U>

await admits any promise payload T, and a value in N at its own type; async return, Promise.resolve of a plain value, catch and finally require N.

Prim is the set of primitives. The record arm needs a lifetime read contract for then, or its absence. Ordinary arrays own no then and have stable prototypes without one. Await reads a native promise's payload once, so any payload is safe, and a value in N is never thenable, so awaiting it yields itself. Promise.resolve keeps an existing native promise through its constructor identity path, so it admits any payload.
