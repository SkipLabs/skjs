2. TypeScript's Awaited

type Awaited<T> =
  T extends null | undefined ? T : // special case
  T extends object & { then(onfulfilled: infer F, ...args: infer _): any } ?
    F extends ((value: infer V, ...args: infer _) => any) ?
      Awaited<V> : // unwrap recursively
    never :
  T; // no declared then

  • Decided from the declared type; distributes over unions; deferred on a type variable.
  • Used by Promise.resolve, Promise.all, and to type await x.

Cases: null or undefined gives itself; an object type declaring then whose first parameter is a function (value: V, ...) gives Awaited of V; a non-function first parameter gives never; every other type gives itself.
