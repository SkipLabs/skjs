# Getting help

SKJS is a TypeScript typechecker written in the Skip language.

- **Bug reports** — SKJS accepts something unsound, rejects valid TypeScript, or crashes: open a [GitHub issue](https://github.com/SkipLabs/skjs/issues) using the matching template.
- **What SKJS accepts or rejects**: see [`skjs-rules.md`](skjs-rules.md), the source of truth for the supported subset.
- **Building, testing, and contributing**: see [`CONTRIBUTING.md`](CONTRIBUTING.md) and the guides it links.
- **Installing a released binary**: see [`docs/binary-distribution.md`](docs/binary-distribution.md).
