SKJS is implemented in Skip (`.sk` files) but is a TypeScript type checker. `.ts` files are user programs that must conform to the SKJS subset.

- The accepted subset is in [skjs-rules.md](skjs-rules.md); never contradict those rules.
- See [README.md](README.md) for build & test commands.
- See [CONTRIBUTING.md](CONTRIBUTING.md) for test writing rules, commit guidelines, and common mistakes.
